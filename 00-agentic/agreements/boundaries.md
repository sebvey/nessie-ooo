# Boundaries

- **The developer's setup is theirs.** Trusting configs, writing local config and secret files, starting services the stack needs: the developer does it. When setup is missing or broken, stop and say what to run; never create or edit those files yourself. To change a value for one command, set it on the command line. `CLAUDE.md` names the files and commands for this project.
- **Don't destroy what you didn't create.** Before a destructive action (reset, drop, delete, overwrite), look at what's there. If anything wasn't created during your session, by you or by something you launched, ask first. Say in your report what you destroyed.
