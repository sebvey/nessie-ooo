# Memory

The repo is the source of truth: anything about the project or the agentic layer (architecture, decisions, conventions, status) goes in the docs, an ADR, `CLAUDE.md`, `00-agentic/` or a ticket, never in the agent's memory. Memory is only for the developer's personal working preferences that don't belong in the repo. When memory and the repo disagree, the repo wins: fix or delete the memory.
