# Memory

The repo is the source of truth: anything about the project or the way we work with the agent (architecture, decisions, conventions, status) goes in the docs, an ADR, `CLAUDE.md`, the agentic layer's files or a ticket, never in the agent's memory. Memory is only for the developer's personal working preferences that don't belong in the repo. When memory and the repo disagree, the repo wins: fix or delete the memory.
