# Tracking

Tickets, one Markdown file each; the folder a ticket sits in is its status (`00-backlog/`, `01-ready/`, `02-in-progress/`, `03-done/`).

The ticket process (statuses, naming, IDs, template) is part of the agentic layer: [`00-agentic/processes/tickets.md`](../00-agentic/processes/tickets.md). The workflow the agent follows: [`00-agentic/agreements/tickets.md`](../00-agentic/agreements/tickets.md).
